# CLAUDE.md and Rules — Writing Guidelines

This project's CLAUDE.md is committed to git and must be team-oriented.

## When updating CLAUDE.md or rules:
- Write in English
- Use impersonal language — no "I", "my", "Luan", or any developer name
- Write as if any new developer should understand it on day one
- Focus on architecture, conventions, and guardrails — not personal preferences
- Never include personal file paths, vault locations, or machine-specific config
- Keep CLAUDE.md under 200 lines — move details to conditional rules

## Personal preferences go in CLAUDE.local.md
- CLAUDE.local.md is gitignored and never shared
- That's where personal paths, current focus, and individual workflow go
